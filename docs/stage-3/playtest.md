# 三區 Alpha 試玩驗收

Linux x86-64 解壓測試包後執行 `./HunterAlive.x86_64`。以新存檔開始，記錄開始、進入各區、讀檔續玩及抵達結局的時間。完成後記錄是否曾需要提示、是否有目標中斷，以及遭遇、掉落與武器效果的問題。

| 區域 | 驗收流程 |
|---|---|
| 崩塌神殿 | 取得蜥翼、擊敗樹靈，滑過西側斷橋並開石門。過場卡按 **E** 進入迴廊。 |
| 淹沒的迴廊 | 沒有提燈時暗水道的閘門會擋住去路。切換獵弓，在石蟹抬起提燈並發光時命中亮點，拾取後穿過暗水道。回到營火存檔並重啟，繼續時應載入同區與提燈，再前往東側出口。 |
| 埋碑內庭 | 避開古門封印者的兩段橫掃，將牠打至半血。護印出現後，在其蓄力亮起時攻擊護印。擊敗後到東側主祭壇按 **E**，查看結局。 |

裝備、武器與怪物的取得或遭遇位置可參照關卡內的補給石匣、營火及圖示。完整試玩須含至少 1 次外部試玩，總數達 3 次。記錄首次通關時間，核對 1–2 小時主線目標。實際遊玩紀錄與外部試玩仍待收集。

## 重現自動檢查

```bash
for suite in tests/scene/stage_3_route_smoke.gd tests/game/stage_3_catalog_smoke.gd; do
  qa_profile=$(mktemp -d /tmp/ultima-stage3.XXXXXX)
  XDG_DATA_HOME="$qa_profile" godot --headless --path . --fixed-fps 60 \
    --script "$suite"
done
```

路線測試從開始頁面建立新檔，以測試站位安排場景，使用實際弓箭輸入取得提燈及破護印。清冊測試核對實際刷怪、寶箱互動、掉落與工坊取得的物品，並確認武器可裝備、物品有圖示。這兩項是自動流程證據，完整首玩及時長使用人工試玩紀錄。
