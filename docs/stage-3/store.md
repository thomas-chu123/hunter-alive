# 商店文案與素材來源

## 短介

在被水與藤蔓吞沒的古代神殿裡，讀懂怪物的攻勢，繳械奪取牠們的能力。用蜥翼飛越斷橋，點亮淹沒的迴廊，尋回封印深處遺失的名字。

## 詳介

《遠古獵人：崩塌神殿》是原創的橫向動作冒險。觀察攻擊前兆，在關鍵時刻用短刀、獵弓或魔法杖反擊。從怪物取得魂技和裝備，回到營火調整配裝，再探索前方未知的遺跡。

穿過崩塌神殿、淹沒的迴廊與埋碑內庭。借蜥翼滑過斷橋，從石蟹手中奪取提燈，在古門封印者的雙段橫掃中尋找空隙。
