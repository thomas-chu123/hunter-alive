# Stage 2 神殿試玩

在 Linux x86-64 解壓後執行 `./HunterAlive.x86_64`。這輪用於確認第一次遊玩的人能辨識招式、在裝備頁換裝，並自行用蜥翼通關。

## 功能驗收

1. 從開始頁面選「新遊戲」。在營火附近按 **E** 取得營火布兜與獵人纏手，關閉營火選單後按 **I** 查看及更換裝備。
2. 到神殿觀景台石匣按 **E**，取得苔織獵衣與餘火魔法杖。用裝備頁或 **Q** 選用武器。按 **J** 往斜上方射出火彈，確認每發消耗一點法力。
3. 觀察石鐘蛾腹部的光。站在落粉範圍內會緩速，蓄力時射中可打斷。擊倒後撿起鱗紗兜帽，再用裝備頁換上。
4. 按 **Esc** 開啟暫停，調整主音量。回營火休息或選「存檔並返回開始頁面」，再選「繼續」，確認音量、持有裝備、身體欄位與選用武器都正確。

## 新玩家試玩紀錄

讓五位首次遊玩的玩家從開始頁面進入。研究人員只觀察與記錄，等試玩結束才說明操作。逐人記錄完成與否、總時間、首次自行裝備蜥翼的時間、在哪一段卡住，以及開裝備頁和辨認石鐘蛾前兆的情況。Stage 2 的通關門檻為五人中至少四人能自行裝備蜥翼並過關，切片長度目標為 15–25 分鐘。

## 重現自動驗收

在專案根目錄執行以下指令，使用獨立暫存存檔。

```bash
qa_profile=$(mktemp -d /tmp/ultima-stage2-qa.XXXXXX)
XDG_DATA_HOME="$qa_profile" godot --headless --path . --fixed-fps 60 \
  --script tests/stage_2_equipment_smoke.gd
```

測試從台階下方起跳，使用遊戲按鍵登上觀景台、開石匣、施法和操作選單。測試用固定位置安排戰鬥與回營火情境。首玩時長及無提示通關率由外部試玩取得。
